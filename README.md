# React + Vite

## Contact form

The contact form sends messages through the [FormSubmit](https://formsubmit.co/) AJAX API to `jessonmaurice.antiporda@gmail.com`. No email credentials are included in the frontend.

After deploying, submit the form once and confirm the activation email that FormSubmit sends to that inbox. Future submissions will then be delivered there, with the visitor's address set as the reply-to address.

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh
